# Multi-note test phrases

Synthetic **monophonic** cello-range melodies for multi-note transcription tests.
Generated by `scripts/generate_multi_note_phrases.py` (additive harmonics).
These are **not** copyrighted solo recordings.

| File | Notes | Rests | Description |
|------|------:|------:|-------------|
| `scale_c_major_cello.wav` | 8 | 7 | Ascending C-major scale fragment in cello tenor range: C3 D3 E3 F3 G3 A3 B3 C4 (quarter notes @ ~100 BPM). |
| `twinkle_opening.wav` | 7 | 6 | Opening of Twinkle Twinkle (public-domain melody) transposed for cello: C3 C3 G3 G3 A3 A3 G3. |
| `open_strings_arpeggio.wav` | 8 | 7 | Cello open-string style arpeggio: C2 G2 D3 A3 then descending A3 D3 G2 C2 (synthetic harmonics, not a real open-string sample). |
| `stepwise_phrase_g.wav` | 9 | 8 | Short stepwise G-minor-ish phrase: G2 Bb2 D3 F3 Eb3 D3 C3 Bb2 G2. |
| `rhythm_quarters_with_rests.wav` | 3 | 2 | Rhythm test @ 100 BPM: C3 (quarter), quarter rest, E3 (quarter), quarter rest, G3 (half). Ground-truth rests are intentional silences. |

Each WAV has a sibling `*_expected.json` with ground-truth MIDI onsets/offsets
(and `expected_rests` when intentional silences were rendered).
Pyin / rhythm output will differ slightly from ideal timing.

`rhythm_quarters_with_rests.wav` is the dedicated rhythm/rest test clip
(100 BPM quarters with quarter-note rests).

Regenerate:

```bash
python scripts/generate_multi_note_phrases.py
```
